# 어휘 탐험

아영 / 인성을 위한 태블릿 우선 한국어 어휘 학습 PWA입니다.

- Supabase 이메일/비밀번호 로그인
- 기기 변경 후에도 학습기록 동기화
- 아이별 날짜별 학습시간·정답률·부분정답·오답 및 기간 조회
- 기본 새 단어 5개 + 복습 단어 최대 10개, 최소 25분 및 모든 목표어의 정확한 문장 사용까지 학습
- 객관식은 로컬 채점, 서술/음성 답변은 OpenAI 서버 채점
- 음성 입력의 STT 오인식은 의미 채점 전에만 보정하며 발음은 평가하지 않음
- PWA 설치 및 자동 업데이트

## 로그인 오류 안내와 기록 재시도 (12.16.20)

로그인 서버의 5xx·요청 시간 초과·네트워크 오류를 이메일·비밀번호 오류와 구분합니다. `invalid_credentials`만 입력 불일치로 표시하며, 이메일 미확인과 요청 제한도 각각 안내합니다. 처리 중 클릭·Enter를 반복해도 로그인 요청은 한 번만 보내고 입력값을 유지합니다. 비밀번호 로그인 HTTP 요청은 12초 후 실제로 취소하며 기존 기록·문제은행 요청의 동작은 변경하지 않습니다.

정상 로그인 응답은 인증 이벤트와 같은 기록 로딩 작업으로 합쳐집니다. 로그인은 성공했지만 기록 읽기가 실패하면 기존 저장 보호를 유지하고 ‘기록 다시 불러오기’를 제공합니다. 이 버튼은 현재 인증으로 기록만 다시 읽으며 비밀번호 제출·계정 생성·확인 메일 발송을 하지 않습니다. 서버 자체의 복구와 화면 수정은 별도로 확인해야 합니다.

검증: `node scripts/verify-auth-recovery.mjs`, 전체 검증 `node scripts/verify-all.mjs`.

## 낮은 단계 미완료 어휘 학습 (12.16.19)

현재 난이도보다 낮은 정수 단계(2단계 이상)의 등록 어휘 전체에서 문장 사용이 확인되지 않은 어휘를 추적합니다. 단어별 저장된 정확한 문장 사용 기록으로 매번 다시 계산하므로 빠른 승급이나 새 문제 교체가 미학습 어휘를 삭제하지 않습니다. 삭제된 1단계 및 제외 표현은 대상에 넣지 않습니다.

기본 새 단어 5개·복습 최대 10개 안에서 최대 2자리를 미완료 어휘에 배정합니다. 이미 시작한 낮은 어휘를 먼저 문장 쓰기로 마치고(복습 슬롯), 아직 배우지 않은 낮은 어휘는 낮은 단계와 이름 순으로 배웁니다(새 단어 슬롯). 나머지는 현재 수준과 기존 복습 정책으로 선정합니다. 보충 목표는 학습 중 난이도가 변해도 교체하지 않으며, 힌트·정답 공개 없이 뜻과 쓰임이 드러나는 문장을 작성해야 완료됩니다. 객관식 성공·카드 소개·과거 숙달 표시만으로는 완료하지 않습니다. 보충 결과는 실시간 등급 조정에 넣지 않습니다. 최소 25분을 위한 추가 새 단어에도 미학습 어휘 후보를 포함하며, 예비 세트는 기존대로 1개입니다.

서버 준비 작업은 현재 단계 근처 어휘와 함께 전체 하위 단계 목록을 읽습니다. 저장 검증은 보충 표시만 믿지 않고, 등록·단계·뜻·미완료 여부·최대 2자리·기존 총량을 확인합니다. 체크포인트의 목표·답안·입력 초안은 보존합니다. 단계별 어휘 목록에는 하위 단계 미완료 개수도 표시합니다.

배포 후 `database/lower-vocabulary-coverage-runtime.sql`을 적용하고 진행 중 세트를 제외한 미사용 세트만 갱신합니다. `app_state`의 답안·등급·기록은 수정하지 않습니다. 검증: `node scripts/verify-vocabulary-coverage.mjs`, 전체 검증 `node scripts/verify-all.mjs`.

## 실시간 난이도 조정 (12.16.18)

답안마다 실력을 추정하고 서로 다른 어휘 3개의 새 평가가 쌓이면 다음 출제 난이도를 조정합니다. 최근 10개 어휘의 첫 무힌트 평가를 사용하며, 객관식보다 회상·문장 사용 근거에 더 큰 비중을 둡니다. 85% 이상이면서 주관식 성공 어휘가 2개 이상이면 0.1~0.3, 같은 평가 묶음에서 상위 단계 어휘 2개 이상을 직접 해결하면 최대 0.5씩 올립니다. 70% 미만이면서 새로 평가한 서로 다른 어휘 3개에서 뜻 이해 실패가 확인되면 0.2~0.3씩 낮춥니다. 이미 확인한 단계의 0.5 이상으로 올라가려면 실제 상위 단계 어휘의 성공이 필요합니다.

해설 후 재연습·같은 어휘의 반복·학습 카드 직후 정답·힌트·정답 공개·미평가·멀리 낮은 단계 문항은 실시간 승급 근거에 추가하지 않습니다. 문장 작성의 실패는 뜻을 모른다는 근거로 가정하지 않고 해당 어휘를 보강합니다. 30초 미제출은 학습시간에만 영향을 줍니다. 순위 등급은 완료 시 실시간 결과를 한 번 확정하고 기존 회차 조정을 더하지 않습니다.

기본 새 단어 5개·복습 최대 10개 및 모든 목표의 문장 사용 완료·최소 25분 규칙을 유지합니다. 현재 표시한 문제, 작성 중인 답안, 이미 학습한 목표와 채점된 답안은 보존합니다. 아직 배우지 않은 새 단어만 같은 개수로 재선택하고 상위 단계 확인 문항은 뜻·예문 카드 없이 먼저 답하게 합니다. 추가 새 단어도 현재 난이도에 맞춰 선택합니다.

개인별 기존 학습 세트와 예비 세트 1개에 인접 단계의 미학습 후보(단계별 최대 4개)를 함께 넣습니다. 후보는 추가 학습 세트가 아니며 선택·소개 전에는 학습량·정오답·숙달에 반영하지 않습니다. 난이도 변경 시 내려받은 검수 문항을 바로 사용하고, 후보 보충은 기존 인증된 문제은행 API로 백그라운드에서 수행합니다. AI 문제 생성을 호출하지 않습니다. 전환에 실패해도 기존 문제·답안을 유지하며, 실패 재요청은 짧은 간격으로 연속 실행하지 않습니다.

체크포인트에 실시간 평가·반영 위치·미사용 후보를 저장합니다. 재실행은 같은 답안을 다시 반영하지 않으며, 이전 버전의 진행 중 학습은 과거 답안을 재채점하지 않고 새로 제출하는 답부터 시작합니다. 보호자 설정 변경도 기존 난이도 설정 보호 및 완료 내역과 함께 복구합니다.

검증: `node scripts/verify-realtime-level.mjs`, 전체 `node scripts/verify-all.mjs`.

## 답안 대기시간 제외 (12.16.17)

한 문제에서 답안 제출 없이 대기하는 시간은 최대 30초까지만 학습시간으로 인정합니다. 이후에는 시간 측정을 자동으로 멈추며, 입력 중인 답안과 문제는 유지합니다. 실제 답안 제출 후 측정을 재개하고, 채점 대기는 계속 제외합니다. 해설·새 단어 카드 화면도 한 화면에서 연속으로 인정하는 시간을 30초로 제한합니다. 입력·힌트·같은 문제 재표시만으로 시간 예산을 새로 주지 않습니다.

누적 시간과 남은 인정 시간을 체크포인트에 함께 저장합니다. 재진입·재실행·백그라운드 복귀로 같은 미제출 문제의 시간 제한을 초기화하지 않습니다. 타이머가 늦게 실행되더라도 시간 계산 자체가 30초를 초과하지 않도록 제한하며, 동일한 측정값을 날짜별 기록과 최소 25분 완료 조건에 사용합니다. 기존에 완료한 회차의 기록은 다시 계산하지 않습니다. 이전 60초 기준으로 저장된 진행 중 문제도 이미 인정된 시간을 보존하면서 남은 인정 시간만 새 30초 기준으로 줄입니다.

## 최소 25분 학습 (12.16.15)

기본 단어의 문장 사용을 모두 확인했을 때 실제 학습시간이 25분보다 짧으면 현재 난이도 범위에서 아직 학습하지 않은 단어를 하나씩 추가합니다. 시간만 채워도 남은 단어의 문장 사용이 확인되지 않으면 완료하지 않습니다. 추가 단어의 최초 객관식·학습 카드와 반복 연습 문항은 고정 문제은행에서 미리 내려받고, 추가 대상이 줄면 다음 후보를 백그라운드에서 보충합니다. 실시간 AI 문제 생성은 호출하지 않으며 주관식 채점은 기존 기능을 사용합니다.

추가 후보는 미리 받은 것만으로 학습 이력에 포함되지 않습니다. 실제로 도입한 단어와 문제·답안·사용 확인·누적 시간·남은 후보를 이어하기에 저장합니다. 휴식·앱 백그라운드·채점 및 문제 다운로드를 기다리는 시간은 학습시간에서 제외합니다. 25분 미만에서 추가 어휘 다운로드가 실패하거나 현재 범위의 새 어휘가 소진되면 완료로 처리하지 않고 저장된 학습의 재시도·휴식을 제공합니다. 이미 완료된 회차 기록과 시작 수준 확인의 기존 완료 규칙은 유지합니다.

## 필수 어휘 보완 (12.16.14)

국립국어원 공식 목록과의 누락 점검에 따라 새 어휘 66개, 일반 뜻으로 다시 구성한 어휘 7개, 기존 1단계에서 2단계로 재분류한 독해 핵심어 10개를 반영합니다. 나머지 1단계 제거 대상 553개와 설명 구절·전문 명칭 제외 정책은 유지합니다. 공식 1~5등급과 앱 단계는 다른 척도이며, 새 앱 단계도 의미와 문맥을 고려한 잠정 분류입니다. 기존 난이도에 맞춘 새 단어 선택과 확인된 약점만 제한적으로 포함하는 복습 규칙을 유지합니다.

어휘당 문맥 선택 3개, 문맥 속 쓰임 3개, 뜻·빈칸 회상 3개, 직접 문장 만들기 1개로 고정 문항 830개를 추가합니다. 회상 예문은 별도로 작성했고 문장 만들기는 예문·상황 설명 없이 목표어만 제시합니다. 인정 가능한 동의어는 회상 답안의 뜻만 인정하며, 목표 단어를 정확히 사용한 독립적인 문장으로 완료해야 합니다. 문항의 독립적인 외부 검수 완료나 공식 학년 대응을 주장하지 않습니다.

`database/essential-vocabulary-seeds.js`와 `database/essential-vocabulary-20261012.json`이 작성·배치 근거이며 `node scripts/build-essential-bank.mjs`로 서버 전용 고정 은행을 재생성합니다. 공개 산출물에는 어휘 메타데이터만 포함하고 문항 아카이브는 `lib/server`에 보관합니다. 새 은행의 영수증과 이전 은행의 영수증을 각각 원래 버전으로 검증하여 이어하기와 사용 지문 기록을 보존합니다.

서버 적용은 `database/essential-vocabulary-bank.sql`로 비공개 은행과 호환 검증을 먼저 설치하고, 새 코드 배포 후 `database/essential-vocabulary-activate.sql`로 어휘를 활성화합니다. 기존 어휘 17개의 이전 행은 비공개 기록으로 보관합니다. 활성화는 아이별 학습 상태를 변경하지 않으며 미소비 준비·예비 세트만 새 내용으로 채웁니다. 검증은 `node scripts/verify-essential-vocabulary.mjs` 및 전체 `node scripts/verify-all.mjs`입니다.

## 1단계 어휘 제거 (12.16.13)

사용 가능한 1단계 어휘 563개를 전체 목록·새 단어·복습·진단·문제은행·문장 템플릿에서 제외합니다. `isRetiredVocabulary`는 등록된 단어 이름과 어휘 단계 모두 검사하여 이전 캐시의 높게 표시된 단계로도 재등장하지 않게 합니다. 어휘 지도는 기존 번호를 유지한 2~9단계입니다. 아이의 난이도 값과 이미 제출한 답안을 다시 계산하거나 초기화하지 않습니다.

`database/retire-level-one.sql`은 이전 어휘 행과 미사용 준비 세트를 비공개 기록으로 보관하고 1단계를 학습 대상에서 제외합니다. 체크 제약으로 1단계 항목의 재승인을 막으며, 해당 단계가 포함된 미사용 세트와 예비 세트만 다시 채웁니다. 소비된 진행 중 세트와 `app_state`를 수정하지 않습니다. 이 파일은 새 서버 배포 완료 후 적용합니다.

이어하기는 채점된 문제와 결과의 원래 위치를 유지하고 미답변 1단계 계획만 정리합니다. 현재 단어가 제거되면 입력 초안을 보관하고 다음 단어에 옮기지 않습니다. 누락된 제거 대상 문항을 다시 생성하지 않습니다. 모든 목표가 제거된 학습은 기존 답안을 보관하고 완료·등급·보상을 만들어내지 않습니다. 정확한 이전 템플릿 영수증은 답안 복구에만 허용하며 새 출제에서는 계속 차단합니다. 과거 학습시간·정답률은 `isRecordedVocabulary`로 기록된 1단계 답까지 유지합니다.

검증: `node scripts/verify-level-one-retirement.mjs`, 전체 검증 `node scripts/verify-all.mjs`.

## 레벨별 어휘 한눈에 보기 (12.16.12)

## 수준에 맞는 목표 어휘 (12.9)

마지막으로 `database/migrations/20261007_target_band.sql`을 적용합니다. 기존 중단 학습과 학습기록은 유지하며 아직 시작하지 않은 다음 학습과 예비 세트에 새 정책을 적용합니다.

새 단어는 목표 어휘 자체를 현재 수준의 ±1 범위에 있는 정수 band에서 고릅니다. 예를 들어 7.4에서는 새 단어를 7~8단계에서 선택합니다. 복습은 실제 학습 이력이 있는 현재 수준의 어휘 가운데 복습 시점과 약점을 우선합니다. 낮은 단계 예외는 정상 복습 범위의 하한보다 최대 두 band 아래까지이며, 최근 30일의 뜻·어휘 회상 첫 시도에서 서로 다른 두 날에 오류가 확인되고 독립 정답으로 회복되지 않은 경우만 최대 2개·실제 복습의 20% 이하로 포함합니다. 7.4에서는 5~6단계만 예외 대상이고 ‘아기’ 같은 1~4단계는 제외합니다. 예전 누적 오답이나 자기 문장의 부분정답만으로 낮은 어휘를 다시 넣지 않습니다. 쉬운 어휘의 지문이나 질문을 어렵게 만들어 채우지 않습니다. 배운 어휘가 없으면 복습 예비 세트를 생성하지 않으며, 하루 최대 5개의 새 단어를 학습하면 해당 어휘로 예비 세트를 준비합니다. 어휘 band는 앱의 편집상 기준이며 표준화된 평가 점수는 아닙니다.

12.16.6은 `database/due-review-5-10-runtime.sql`의 복습 검증을 서버에 적용합니다. 새 예비 세트와 브라우저 선정에 같은 상대 수준·최근 의미 약점 기준을 사용하며, 이전 작업자의 정책도 배포 중에는 같은 강화된 검증으로 확인합니다. 이어하기에서 제출한 답안·학습 기록·현재 문제·입력 초안은 그대로 두고, 더 이상 선정되지 않는 단어의 남은 반복과 완료 의무만 보류합니다. 초급 학습자의 1~2단계 복습, 새 단어 5개와 복습 최대 10개, 각 선정 단어의 정확한 자기 문장 완료 기준은 유지합니다.

개인별 예비 세트는 1개이며 소비 직후 당시 수준에 맞춰 보충합니다. 복습일 이전의 활용 연습에는 장기 회상·복습 간격을 높이지 않습니다. 기본 단어는 최대 15개이며 활동 수는 고정하지 않습니다. 각 단어의 자기 문장 사용을 확인할 때까지 유형을 바꿔 재연습합니다.

독립 검수의 `levelDemandFit`는 지문 길이와 별개로 의미 구별·선택지 타당성·활용 수준을 검사합니다. 자연스러운 유의어를 오답으로 처리하지 않습니다. 고급 빈칸이 쉬운 답으로 풀리는 경우 직접 활용 문제로 다시 구성하고 검수합니다.

## 12.16.5 추가 연습의 문제은행 사용

최초 세트뿐 아니라 새로 추가한 반복 문제에서도 문제은행을 먼저 사용합니다. 요청한 유형의 미사용 지문이 없으면 같은 어휘의 뜻 회상·다른 객관식·자기 문장 만들기를 순서대로 찾아 반환합니다. 서버가 명시한 유형 전환은 해당 추가 계획에만 반영하며 현재 문항과 제출한 답안을 바꾸지 않습니다. 사용한 지문과 준비된 지문의 중복 검사는 유지합니다. 자기 문장을 정확히 만든 경우에만 완료하고, 객관식·회상 정답만으로 완료하지 않습니다. 기존 학습 정책과 예비 세트는 유지하며 문장 채점은 의미 기반 AI 채점을 계속 사용합니다. 은행 미등록 어휘의 부족 문항에는 기존 생성·검수 경로가 필요합니다.

## 12.16.4 학습 완료 기준

하루 새 단어 5개 + 서로 다른 복습 단어 최대 10개를 선택합니다. 현재 수준의 복습 예정일과 최근 약점을 먼저 판단하고, 비슷한 우선순위에서 문제은행 준비 여부를 고려합니다. 후보가 부족하면 가능한 분량만 복습합니다. 낮은 단계의 확인된 약점은 최대 2개·실제 복습 단어의 20% 이하로 제한합니다. 첫 활동은 뜻 회상/쓰임 구별/문장 사용으로 나누며, 객관식이나 뜻 회상 정답으로 단어를 완료하지 않습니다. 목표 단어를 넣어 뜻과 쓰임이 드러나는 자기 문장이 만점이고 힌트·정답 공개가 없을 때만 해당 회차에서 완료합니다. 예문이나 상황을 제시하지 않습니다.

미완료 단어에는 한 활동씩 추가합니다. 문장 실패 후 쓰임 구별, 그 다음 다시 자기 문장 만들기로 유형을 바꾸며 시도 수 상한이 없습니다. 새 지문 중복 검사는 과거 문장과 준비된 문장 모두 확인합니다. 완료한 단어는 반복하지 않습니다. 첫 답과 모든 재연습 기록을 보관하되 재연습은 회차 등급 계산에서 제외합니다. 장기 기억 숙달은 기존 간격 회상 기준을 유지합니다.

잠시 쉬기는 완료나 등급 조정을 주장하지 않고 답안·추가 계획·진행 순서·힌트를 저장합니다. 기존 중단한 회차의 원래 문제와 답안도 보존합니다. 서버 준비/소모/예비 세트 검사는 고정 20문항 대신 모든 계획 인덱스가 준비되었는지 확인합니다. 배포 전 database/unlimited-usage-practice.sql을 적용합니다. 문제 생성과 의미 기반 문장 채점은 연결된 API의 정상 응답이 필요하며, API 오류를 오답으로 기록하지 않습니다.
