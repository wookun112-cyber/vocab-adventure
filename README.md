# 어휘 탐험

아영 / 인성을 위한 태블릿 우선 한국어 어휘 학습 PWA입니다.

- Supabase 이메일/비밀번호 로그인
- 기기 변경 후에도 학습기록 동기화
- 20~30문제 적응형 일일 학습
- 객관식은 로컬 채점, 서술/음성 답변은 OpenAI 서버 채점
- 음성 입력의 STT 오인식은 의미 채점 전에만 보정하며 발음은 평가하지 않음
- PWA 설치 및 자동 업데이트

## 문제은행과 예비 학습 (12.7)

`database/question-bank.sql` 다음 `database/migrations/20261007_question_bank_integration.sql`을 적용합니다. 새 작업자를 먼저 배포하면 기존 문제 준비 기능을 유지한 채 전환할 수 있습니다.

독립 AI 검수와 문장 검사를 통과한 문제만 계정별 비공개 문제은행에 저장합니다. 어휘·활동 종류·읽기 수준·도움 수준·문항 정책이 맞고 사용한 문장과 겹치지 않는 문제를 우선 선택합니다. 부족한 문항만 생성합니다.

프로필별로 복습 전용 20문항 예비 세트 한 개를 순서대로 준비합니다. 당일 새 단어 3개를 마친 뒤 이어 학습하면 검증된 예비 세트를 승격합니다. 읽기 수준, 도움 수준, 사용한 문장, 학습한 어휘를 다시 확인하며 기존 중단 학습은 원래 순서대로 복구합니다. 소모 즉시 보충을 시작하며, 작업을 시작하는 시점의 난이도를 사용합니다. 기존 분당 큐는 실패나 중단 때 재시도합니다. 새 날의 새 단어 학습은 기존 일일 큐가 준비합니다.

비공개 테이블은 RLS를 적용하고 직접 API 접근을 허용하지 않습니다. 작업자의 저장에는 작업 ID, 비공개 capability, 현재 lease가 모두 필요합니다. 준비 과정은 학습기록을 변경하지 않습니다.

기존 12.7.0 설치에는 `database/migrations/20261007_one_review_reserve.sql`을 적용합니다.

검증: `node scripts/verify-all.mjs`.

## 수준에 맞는 복습 (12.8)

마지막으로 `database/migrations/20261007_level_fit.sql`을 적용합니다. 기존 중단 학습과 학습기록은 유지하며 아직 시작하지 않은 다음 학습과 예비 세트에 새 정책을 적용합니다.

현재 수준에서 두 단계 이상 낮은 어휘는 기본 20문항 중 최대 4문항, 기초 회상은 최대 2문항입니다. 낮은 단계 어휘의 기준은 `max(1, floor(현재 수준)-1)`보다 낮은 band입니다. 현재 수준과 가까운 학습 어휘는 복습일 이전에도 활용 연습으로 선택할 수 있으며, 이때 장기 회상·복습 간격을 높이지 않습니다. 새 단어는 하루 최대 3개입니다.

높은 단계 학습 어휘가 아직 하나도 없는 경우에는 새 단어를 추가하지 않고 배운 단어의 의미 판단·직접 활용을 심화합니다. 이 경우 기본 회상은 최대 2문항이고, 어휘 자체의 band는 변경하지 않습니다. 어휘 band는 편집상 권장 범위이며 문항 난이도의 실측값이 아닙니다.

독립 검수의 `levelDemandFit`는 지문 길이와 별개로 의미 구별·선택지 타당성·과제의 활용 수준을 검사합니다. 자연스러운 유의어를 오답으로 바꾸어 난이도를 높이지 않습니다. 고급 빈칸이 넓고 쉬운 답만으로 풀리는 경우는 문항을 다시 생성합니다. 심화 문장 사용의 채점은 목표어의 자연스러운 의미와 요청한 상황·이유·조건·결과의 표현을 확인합니다.
