# 어휘탐험 어휘 난이도·선정 2차 재점검 (2026-10-06)

## 목적과 구분
- 대상: 초1~고등 심화 단계의 한국어 어휘 학습 DB
- 목표: '6,000개 정확히' 대신 5,000~7,000개 범위에서 학습 가치와 어휘 독립성을 우선
- **단계(band)는 권장 학습 난이도 추정치**입니다. 해당 어휘의 '교육부 공인 최초 등장 학년'을 뜻하지 않습니다.

## 근거 자료와 적용 범위
1. 국가교육과정정보센터(NCIC)의 2022 개정 교육과정 고시 및 초중등 성취수준 자료
   - https://ncic.re.kr/bbs/eduSian2022/view/547.do
   - 중학교 국어: https://ncic.re.kr/bbs/standard/view/773.do
   - 고등학교 국어: https://ncic.re.kr/board/B0024.cs?act=read&bwrId=2044
2. 봉미경·김한샘·김선혜(2022), 「교과서 분석 기반 초등 교육용 어휘 선정 연구」. 초등 전 학년·전 과목 교과서 말뭉치에서 21,213개 어휘를 선정·등급화한 연구.
   - https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002886227
3. 국립국어원 표준국어대사전: https://stdict.korean.go.kr/

**검증 한계:** 위 자료를 기준·검토 범위로 참고했으나 5,622개 각각을 교과서 원문·국립국어원 표제어 DB와 자동 매칭한 것은 아닙니다. 즉 모든 단어의 개별 등장 학년을 독립적으로 입증한 검증이 아닙니다. 정확한 수록 학년이 필요한 경우 저작권과 접근 조건을 지킨 교과서 코퍼스의 전수 대조가 추가로 필요합니다.

## 사용한 추가 선별
- 기존 항목의 뜻, 예문, 학습 단계, 도메인, AI 검수 점수·플래그를 확인
- 'noncanonical_phrase'·'too_specialized' 플래그와 긴 서술 구문을 조합하여 우선 심사
- 단어가 아니라 상황 설명에 가까운 긴 조합 표현은 독립 학습 어휘에서 제외
- '인수 정리', '수소 결합', '유전자 풀' 등 정착된 교과 개념어는 복원·유지
- 제외 항목은 물리 삭제하지 않고 `quality_status='rejected'`로 보관
- `curriculum_validation_audit`에 2차 조치와 이전 상태를 기록. 복원 가능
- `curriculum_words.grade_basis`는 학년별 실측 자료가 아니라 **학습 단계 추정**임을 표시

## 결과
- 2차 선별 시작: 학습 가능 **6,000개**
- 2차 후보 심사: **389개**
- 독립 교과 개념어로 재판정 후 복원: **11개**
- 추가 보관(학습 제외): **378개**
- 최종 학습 가능: **5,622개**
- 중복 단어: **0개**
- 뜻·예문 누락: **0개**
- 기존 검수 점수 없는 학습 가능 단어: **0개**
- 기존 AI 검수 점수 평균: 약 **89.71/100**. 이 점수는 **교육과정 일치율/임상적 타당도/시험 등급의 인증값이 아니라 AI의 자체 평가 결과**입니다.
- 향후 개선: 실제 교과서 어휘빈도 자료의 사용 권한 확보 후 개별 어휘 출현/학년 분석과 학습자 정답률 기반 단계 보정

## 운영상 원칙
1. 5,000~7,000개 내 품질 위주, 개수 맞추기용 자동 보충 금지
2. 학년 경계는 절대적 기준이 아닌 출발점이며 학습 성취도에 따라 난이도를 조정
3. 오류 제보와 자료 근거가 생기면 개별 어휘·단계를 재검토하고 감사 내역 유지
