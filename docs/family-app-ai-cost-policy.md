# AI 비용 최소화 기본 설계 — 모든 가족용 앱 공통 원칙 (2026-10-14)

## 기본 원칙

콘텐츠 제작과 실시간 사용자 서비스를 분리한다.

1. **사전 제작:** 문항, 모범 답안, 자세한 해설, 예문, 난이도 메타데이터, 고정 대사, 음원 등은 ChatGPT에서 직접 초안 작성·검토하고, 결정적 구조 검사 및 표본 테스트 후 버전 관리된 데이터베이스에 저장한다. 별도의 OpenAI API로 대량 제작·검수를 반복하지 않는다.
2. **서비스 제공:** 학습자가 앱을 실행하면 이미 저장한 자료를 읽는다. 객관식 채점, 정답 해설 표시, 문제 순서·복습 간격·난이도 조절과 통계는 가능한 한 규칙 기반으로 처리한다. 같은 정적 정보를 다시 AI에 요청하지 않는다.
3. **실시간 AI 허용:** 사전 정답표나 로컬 로직으로 의미 판정이 불가능한 자유 문장, 음성 내용 인식, 대화 상대의 자유 응답에 한정한다. 실패/통신 오류는 학습 결과를 '확인 필요'로 남기며 의미 채점 실패로 처리하지 않는다.
4. **문제은행 부족:** 이미 작성한 동등한 품질의 다른 문항/검증된 고정 템플릿을 사용하고, 둘 다 없으면 부족한 문항을 관리자 보충 대상으로 남긴다. 사용자 입력과 학습 이력을 보존한다. 학습 중 자동으로 유료 문제 생성·검수 API를 호출하지 않는다. 특히 난이도·문항 유형·50:50 비율을 해치는 무조건적인 대체는 금지한다.
5. **추적 및 상한:** 모든 유료 호출에 앱, 기능, 모델, 요청 수, 입력/출력 토큰, 상태, 처리 시간 및 추정 비용을 기록한다. 콘텐츠 제작 대량 작업에는 사용자가 승인한 예산 상한을 둔다. 앱별로 API 키/프로젝트를 분리해 청구를 구분하고, 원문 답안과 인증 정보를 로그에 저장하지 않는다.
6. **캐시:** 동일한 사용자의 동일 답변 재채점과 같은 의미의 해설 재생성은 캐시한다. 캐시 키에는 채점 정책·모델·답변이 포함돼야 하고, 개인정보 접근 제어와 만료 정책을 따른다.
7. **품질:** AI 사용량 최소화 때문에 뜻 확인 없이 단어만 보고 정답 처리하거나, 정답 문장을 복사하면 실력이 올라가게 만들지 않는다. 구체적인 학습 목표에 필요한 의미 판정은 유지한다.
8. **배포:** 기존 학습 이력, 가족 프로필, 음원, 사용 중인 세션을 잃지 않도록 안전한 버전 전환과 사전·사후 검증을 거친다.

## 앱별 정책

- **어휘탐험 (Vercel + Supabase):** 교육용 문제 생성과 독립 AI 검수 호출을 학습 준비에서 제거하고, 고정 문항 및 로컬 템플릿을 우선 사용한다. 자유문장 의미 채점만 필요 시 서버 API를 이용한다. 문제 부족은 로그와 준비 실패 상태로 보고하고 기학습 상태는 보존한다.
- **English Path (ChatGPT Sites):** 저장된 문제은행, 정답·해설, 수준별 독해, 단어·문법 예문과 다음 문제 선택을 로컬/DB 로직으로 처리한다. 음성 이해와 자유회화, 다양한 자유답변의 의미 판정만 실시간 AI 호출을 허용한다. 고정 표현은 모범 답안을 캐싱해 중복 채점 비용을 피한다.
- **별너머 탐험대 (ChatGPT Sites):** 사전 제작 드라마 대본·고정 캐릭터 대사·장면 음원을 재사용한다. 매번 읽기·표시·음원 재생에 OpenAI/ElevenLabs 실시간 생성 비용이 들지 않도록 한다. 어린이 선택에 따라 이야기 진행 분기만 정적 규칙으로 처리하고, 실제 개방형 대화가 필요한 상황만 AI 호출한다. 음성 생성 결과의 자산과 권리 관계를 먼저 확인한다.
- **HOUSELAB 및 신규 앱:** 정적 아파트 DB·평형 정보·표준 견적표·계산식·FAQ는 데이터베이스/규칙으로 처리한다. 사용자의 새로운 자연어 상담이나 비정형 문서 이해 등 별도 AI가 꼭 필요한 기능만 호출한다.
- **별도 호스팅의 미확인 앱:** 소스 저장소와 실행 로그가 확인되면 같은 기준으로 개별 심사한다. 직접 확인되지 않은 앱을 수정했다고 주장하지 않는다.

## 배포/검수 체크리스트

- 모든 학습 문제 준비 HTTP 핸들러에서 콘텐츠 생성 API 호출이 0인지 테스트
- 동일 저장 문제를 두 번 제공할 때 AI 호출 0인지 테스트
- 객관식·고정 해설·스토리 음성 재생 시 API 호출 0인지 테스트
- 자유 응답 채점은 필요 시에만 1회 호출하고 반복 제출 시 중복 과금 방지
- 은행 부족 시 원문 답안과 진행 중 문제·학습 기록 보존
- 변경 전후 앱별·기능별 유료 API 호출 건수와 비용 비교
