# 어휘탐험 12.16.48 — 학습 시작·채점 응답 개선 (2026-10-22)

## 유지하는 안전 장치

- 기본 학습 묶음 전체가 검수·저장되었는지 확인하는 서버 조건은 변경하지 않는다. 첫 문제만 준비되고 나머지 문제가 끊기는 것을 막는다.
- 직접 쓴 문장의 의미 채점은 기존 모델, 원래 답안 및 동일한 1회 채점 요청을 유지한다. 모델을 임의로 가볍게 바꾸거나 키워드 기반 부분정답으로 성급하게 처리하지 않는다.
- 클라우드 동기화·복습 일정·독립 회상 및 승급 점수는 AI 응답이 **실제 확정된 후에만** 갱신한다. 채점 대기 상태는 절대 정답으로 표시하지 않는다.

## 변경 사항

1. **학습 시작:** 서버 준비 상태의 초기 조회를 빠르게 시작하고 550/900/1400/1800/2200ms 간격으로 최대 5번 확인한다. 전체 문제 검수 완료 조건과 소비 원자성은 유지한다. 이미 payload가 반환된 준비 상태의 읽기 갱신 간격은 2초에서 1.1초로 단축한다.
2. **문제 준비 CPU:** 상·하 인접 단계 후보를 준비할 때 2,815단어 고정 커리큘럼을 각 단계마다 재보정하지 않고 1번만 구성해 공유한다. 예비 문제 개수나 검사 규칙은 바꾸지 않는다.
3. **문장 채점:** 1.6초 안에 결과가 확정되면 기존처럼 즉시 정답·해설을 표시한다. 그 이후에는 원답안을 로컬/클라우드 체크포인트에 보관하고 "채점 중 · 다음 문제 진행"으로 전환한다. **이미 시작한 서버 요청은 1.6초에 중단하지 않으며 새 유료 요청도 만들지 않는다.**
4. **결과 도착:** 원 요청이 완료되면 정답·해설을 정해진 뒤쪽 피드백 작업에 1번만 추가하고, 앱이 마지막 문항에서 대기 중이면 즉시 이를 보여준다. 요청 실패 시 보관된 ID에 대해 읽기 전용 상태 조회를 계속 사용하고, 서버가 명시한 재시도 가능 상태에서만 새 요청을 허용한다.
5. **복구 영수증:** 서버가 응답한 providerReceipt/gradeReceipt를 원 제출 작업과 함께 저장해 GET 기반 조회에서 사용한다. 실행 중 앱을 닫아도 기존 답안을 보존한다.
6. **평가 보존:** 잠깐 저장한 "채점 대기" 가짜 행은 이전 학습·독립 시도 여부 계산에서 제외한다. 원래 답변의 학습·숙달 효과가 누락되지 않도록 한다.
7. **PWA:** 서비스워커 캐시 및 version.json 12.16.48로 갱신한다.

## 검증과 한계

- 기존 회귀 테스트와 실제 브라우저 복구 테스트를 통과해야 배포한다.
- 추가 테스트는 1.6초 이후 UI 전환, 동일한 요청 1건 유지, 결과 전달 1회, 독립 평가·복습 원본 보존, providerReceipt 후속 조회를 확인한다.
- 이 개선은 학습자가 답안을 기다리는 시간을 줄이며, AI 추론 자체의 서버 처리 시간을 1.6초로 줄인다는 뜻이 아니다. 학습 시작도 안전한 전체 패킷 준비 시간 자체는 남는다.
- Vercel 실시간 실행 로그의 접근 제한으로 실사용 분포는 별도 확인이 필요하다. 일정 시간 동안 사용 후 시작 로딩·채점 대기의 중위수와 p95를 비교해야 효과를 최종 측정할 수 있다.
