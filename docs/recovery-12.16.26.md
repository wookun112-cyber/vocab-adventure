# 저장 복구와 다음 날 새 학습 — 12.16.26

## 저장
변경사항 없는 저장에서 완료된 Promise가 cloudSaveTask에 남아 다음 쓰기 요청을 막는 경우를 재현했다. 저장 작업을 Promise microtask에서 시작해 작업 포인터를 정상 해제한다. 실패한 저장은 false를 반환하고 기기의 기존 데이터를 보존한다. HTTP 요청 자체에 12초 취소 신호를 적용하고 15초 화면 대기 제한을 유지한다. 오류는 완료된 저장으로 표시하지 않으며, 재시도 성공 시 오류 상태를 지운다. 서버 로그에는 오류 코드와 수정 항목 수만 남기고 답안은 기록하지 않는다.

## 날짜가 바뀐 미완료 학습
한국시간의 학습 시작일을 기준으로 이전 날짜의 daily/review 학습이 남아 있으면 기본 버튼은 '오늘 새 학습 시작'이다. '이전 학습 이어하기'도 선택할 수 있다. 오늘 새 학습을 선택하면 먼저 현 기기 기록을 서버에 저장한 뒤, 서버 트랜잭션으로 이전 세트를 비공개 paused_lessons에 보관하고 새 학습을 준비한다. 당일 미완료 학습은 원래대로 이어간다. 같은 세트를 강제로 완료하지 않는다.

보관 자료에는 원래 문제, 제출 답안, 학습시간, 미제출 초안, 힌트, 채점 대기 작업을 유지한다. 완료 회차, 점수, 어휘 통계, 난이도, 보상을 임의로 추가하거나 재계산하지 않는다. 새 학습은 새 학습시간으로 시작한다. 보관된 학습은 홈의 '보관된 미완료 학습'에서 다시 열 수 있고, 채점 대기 답안은 그 학습을 이어갈 때 기존 채점 큐로 확인한다. 복원 전에 현재 진행 중인 세트가 있으면 그 세트도 보관한다.

## 검증
- 실제 배포용 변환 소스에 대해 변경 없는 저장 뒤 새 쓰기, 저장 실패와 재시도, 한국시간 자정 경계, 날짜 전환, 이전 학습 명시적 이어하기, 저장 실패 시 전환 금지 회귀 테스트를 실행한다.
- Supabase에서 이전 날짜 세트의 보관·원본 그대로 복원·중복 요청·다른 프로필 불변·학습 증거 불변을 트랜잭션으로 시험하고 롤백했다.
- 당일 학습의 잘못된 보관과 다른 활성 세트 ID의 요청을 차단하는 시험을 통과했다.
- 비로그인 RPC 실행 및 브라우저의 보관 테이블 직접 접근은 차단한다. 보관 테이블은 RLS가 활성화되어 있다.
- 시험용 답안·점수·보관 세트는 운영 데이터에 남기지 않았다. 테스트에 유료 AI 호출을 사용하지 않았다.

실제 사용자의 태블릿 조작은 별도 확인 대상이다.
