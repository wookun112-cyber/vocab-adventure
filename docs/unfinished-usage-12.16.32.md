# 미완료 어휘 이월과 간격 복습

- 매 학습 체크포인트에서 미완료 목표를 별도로 보존한다. 객관식 정답, 힌트 사용, 예문 복사, 채점 대기는 문장 사용 완료로 인정하지 않는다.
- 다음 날 새 세트의 복습 최대 10개에 미완료 목표를 먼저 배정한다. 난이도 변경·과거 사용 성공·먼 복습 예정일 때문에 누락시키지 않는다. 초과분은 목록에 남는다. 제외된 1단계/표현은 부활시키지 않는다.
- 문장 사용에 성공하면 이월 대상에서 해제한다. 늦게 복원한 과거 학습은 이후 완료한 어휘를 다시 미완료로 바꾸지 못한다. 복습 세트에서도 문장 사용을 다시 완료해야 한다.
- 최초 사용 완료 후 다음 날부터 확인하며, 독립 회상 성공으로 1·3·7·14·30·60일 간격을 적용한다. 힌트/오답은 단계와 간격을 초기화한다. 같은 날 후속 문장 연습이 이미 늘어난 복습 간격을 다시 하루로 줄이지 않는다. 실제 출제는 미완료 우선순위와 하루 복습 10개·25~30분 한도 내에서 이루어진다.
- `unfinished-usage.sql`은 날짜 전환 시 원자적으로 이월 목록을 보존한다. 기존 보관 학습과 현재 학습의 미완료 목표도 반영한다. 기존 답안·점수·시간은 그대로 유지한다. 적용 전후 세 프로필에서 이월 필드를 제외한 전체 기록 해시가 일치했다.
- 검증: 순수 모델의 이월/완료/지연 복습, 실제 서버 준비 함수의 고정 문제은행 제공, SQL 보관/정답/힌트 판정, 전체 배포 회귀 검사. 실제 아이의 답안 제출이나 유료 모델 호출은 하지 않았다.
